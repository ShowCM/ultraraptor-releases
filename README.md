# Ultraraptor

**A desktop workspace for AI-assisted software development.**

Ultraraptor brings projects, terminal sessions, Git Worktrees, files, and development tasks together in one native macOS application.

Work across multiple projects, keep independent terminal sessions organized, and manage your development workflow without juggling separate terminal windows.

**Free V1 Beta · macOS · Apple Silicon**

## Download

**Latest beta: v0.1.0-beta.1**

Download Ultraraptor from the [GitHub Releases](../../releases) page once the first beta is published.

Ultraraptor Free V1 is currently available for Apple Silicon Macs running macOS 15.0 or later.

## Installation

1. Download `Ultraraptor.dmg` from GitHub Releases.
2. Open the downloaded DMG.
3. Drag **Ultraraptor** into **Applications**.
4. Open Ultraraptor from Applications.

### Opening Ultraraptor for the First Time

Ultraraptor is currently distributed without Apple Developer ID signing or notarization. Because of this, macOS may display a security warning when you try to open the app for the first time.

If macOS blocks the app, open **System Settings → Privacy & Security**, scroll down to the Security section, and click **Open Anyway**. Confirm the action when prompted. You should only need to do this once for the installed version.

There is no need to disable any macOS security settings.

## Features

### Project management

Register local projects and switch between them from one workspace. Each project keeps its own workspace organization and file navigation.

### Integrated terminals

Run independent terminal sessions directly inside Ultraraptor. Work with your existing command-line tools and AI coding agents, including Codex CLI.

### Git Worktrees

Create separate working directories and Git branches for parallel development. Reuse available local branches and manage Worktrees with safeguards against accidental file loss.

### File explorer and editor

Browse project files, search for content, open files, and make edits without leaving the application.

### Workspace organization

Group terminals and editor tabs into workspaces. Organize different development activities within the same project.

### Local development tasks

Manage project tasks inside Ultraraptor without relying on a separate task-management service.

## System requirements

- macOS 15.0 Sequoia or later
- Apple Silicon (M1 or newer)
- Git for Git Worktree functionality
- Codex CLI or other development tools installed separately, if you intend to use them

Intel Macs, Windows, and Linux are not currently supported.

## Beta status

Ultraraptor is an early beta release. Features and data formats may change, and some workflows may contain bugs.

Before using Ultraraptor for important work, maintain independent backups and keep your projects under version control.

The current beta does not include automatic updates or a signed, notarized installer.

## Feedback and bug reports

Found a bug or have a feature suggestion? Please open an issue in this repository.

When reporting a bug, include your macOS version, Ultraraptor version, steps to reproduce the problem, and relevant screenshots or error messages. Do not share passwords, access tokens, or private project data.
